Fast diagnosis

Read failures by layer

11
401

Identity

Check token audience, delegated scope, tenant, expiry, and sign-in state.

403

Authorization

Check agent sharing, environment access, consent, licensing, and policy.

404

Routing

Check publication, environment, schema case, harness, endpoint family, and API version.

200 + wrong result

Runtime

Confirm the published version, orchestration, tool connections, and correct harness path.

Final-only responseA complete answer without progressive chunks is not automatically a connection failure.
Access denied after connectTransport success does not prove the conversation identity is authorized for the agent.
Separate identity, authorization, routing, and runtime behavior. Diagnose from the status code inward
